ASA = Arena Semantic Annotations, the faceted tag standard for arena_models assets, designed + implemented 2026-07-02/03. UPDATE 2026-07-20: the workspace vcs-mirror `deps/arena_models` is now COMMITTED + clean (HEAD d4d8a13 "semantic annotations!"), separately versioned (`asa: 1` / `CURRENT_ASA = 1`) with a GCS publish pipeline; for planning it is NOT a free "blank slate" (edits need ASA-rev bump + DB rebuild + GCS re-upload + fetch-cache invalidation). Verified this session: the ASA tag grammar is `[a-z0-9_]+` segments only (CANNOT encode floats/axes/poses), `machines: {}` is reserved-empty and never read, and `hoi=[lie,see,sit,touch]` is a flat label (no openable/articulation/anchor facet) -- so any M4 articulation/anchor data needs a NEW structured (non-tag) schema, not a facet addition. Lives in `arena_models/semantic/` (plain subpackage, import-light: stdlib+attrs+yaml): `asa.yaml` (the spec, v1), taxonomy.py, lint.py, fixes.py, ASA.md. User decisions: bundled with arena_models (NOT own dist/repo, "tightly coupled, want them together"), advisory linter not hard gate (autopep-style, severities + --fix), spec-as-data (asa.yaml shippable to bucket).

- Grammar: `key::path::value`, lowercase [a-z0-9_]+ segments, last segment = value. Facets: domain (multi), kind (single, per-class vocab), mount, room, hoi (multi, ORDER-SENSITIVE: first hoi:: tag = ProcTHOR primaryProperty), color, material (object-only), human::gender/ethnicity/age/role (peds), origin. `asa: 1` stamp in every annotation. ASA scope = semantics ONLY: bounding_box/face/derived extents are first-order geometric properties outside the standard (user insisted). machines chapter reserved (door/elevator/ped_locomotion state machines later, bindings live where the entity is declared, actuation per-simulator). User style rulings: NO "legacy" vocabulary anywhere (pre-1.0 old shapes simply don't exist, lint code is "bare-tag"), no field-lift machinery kept in lint/fixes after the one-time migration ran, no tombstone comments.
- Structs: MaterialAnnotation is a primitive Annotation subclass, SpatialAnnotation(bounding_box/face/note) base for ObjectAnnotation(+hoi) and HumanAnnotation, AssetType.HUMAN + HumanDatabaseBuilder (copytree+index). as_metadata promotes facets to Chroma columns ("human.gender", "domain"), as_text flattens tags to words (embed:false facets like origin/mount excluded).
- CLI: `arena-models semantic lint PATH [--fix] [--json]`. fixes.py has name→kind token tables verified 100% against the prod inventory (268 objects, 413 materials) + exact-name overrides (Lab_Bench→counter, Volga_Blue→stone, Diamond_Plate_*→metal), color/material value normalization (grey→gray, "light yellow"→yellow, porceplain→porcelain), room:: lifted from bare kitchen/bedroom/livingroom/bathrooms tags.
